Burgers Of Fury (Unreal Engine 5)

Burgers Of Fury is a third-person action game developed independently in Unreal Engine 5 as my Year 12 Design and Technology major project. The project involved designing, implementing and testing a complete game from the initial concept through to the final playable release.

The game was built using Unreal Engine Blueprints, allowing me to develop gameplay systems, enemy AI, combat mechanics, player animation and user interface design while learning the fundamentals of game development and software design.

Note: This repository contains the project's documentation. The playable game can be downloaded from itch.io.

Features
Third-person player movement
Player animation using Animation State Machines
Melee combat system
Enemy AI using Behaviour Trees
Health and damage system
Level progression
User Interface (UI) and HUD
Interactive gameplay mechanics
Technologies Used
Unreal Engine 5
Unreal Engine Blueprints
Behaviour Trees
Animation Blueprints
State Machines
What I Learned

This project was my introduction to developing a complete game independently. Throughout the project I gained experience in:

Designing gameplay systems from scratch
Implementing AI behaviours and combat mechanics
Creating player animations using state machines
Debugging and testing gameplay systems
Managing a long-term software project from concept to completion

It also strengthened my problem-solving skills and sparked my interest in software and game development, which ultimately led me to pursue Computer Science at university.
